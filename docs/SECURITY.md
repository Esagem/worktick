# Security & Secrets Handling

This project has four secrets that must never end up in version control:

| Secret | Where it lives at runtime | Rotated by |
| ------ | ------------------------ | ---------- |
| `GOOGLE_CLIENT_ID` | Fly secrets | Google Cloud Console |
| `GOOGLE_CLIENT_SECRET` | Fly secrets | Google Cloud Console |
| `API_SHARED_SECRET` | Fly secrets + each device locally | Generate with `python -c "import secrets; print(secrets.token_urlsafe(32))"` |
| `HOURLY_RATE` | Fly secrets | (not really a secret — just personal) |

---

## Local development setup

### Backend

```bash
cp backend/.env.example backend/.env
# Edit backend/.env with your real values
```

`.env` is gitignored. The backend reads it via Python's `os.environ.get()`.

### Android

```bash
cp android/local.properties.example android/local.properties
# Edit android/local.properties — set BACKEND_URL and API_SECRET
```

`local.properties` is gitignored AND auto-generated by Android Studio per machine. The `app/build.gradle.kts` reads these values and exposes them as `BuildConfig.BACKEND_URL` and `BuildConfig.API_SECRET` to your Kotlin code. The values are baked into the compiled APK but are not in source control.

### iOS

```bash
cp ios/WorkTickConfig.example.swift ios/WorkTickConfig.swift
# Edit ios/WorkTickConfig.swift — set backendURL and apiSecret
```

`WorkTickConfig.swift` is gitignored. Add it to your Xcode project; do not check it in.

## Pre-commit protection

This repo includes two layers of protection:

### 1. Local pre-commit hook (one-time setup)

```bash
git config core.hooksPath .githooks
```

After running this, every `git commit` will scan staged files for common secret patterns. If anything looks suspicious, the commit is blocked. Bypass with `--no-verify` only if you're certain it's a false positive.

### 2. GitHub Actions secret scan

`.github/workflows/secret-scan.yml` runs [gitleaks](https://github.com/gitleaks/gitleaks) on every push and PR. If a secret-shaped string sneaks through and gets pushed, the action fails and tags the commit. **This catches what the hook misses.**

### Manual scan

Before any push to a public branch:

```bash
# Install gitleaks once: https://github.com/gitleaks/gitleaks#installing
gitleaks detect --source . --verbose
```

## "I think I leaked a secret. Now what?"

**Speed matters.** Anyone watching public GitHub feeds can grab leaked secrets within minutes.

### 1. Rotate immediately

Don't try to delete the commit first. Rotate first, delete later.

#### `API_SHARED_SECRET`
```bash
new=$(python -c "import secrets; print(secrets.token_urlsafe(32))")
echo "New secret (save it): $new"
fly secrets set API_SHARED_SECRET="$new"
# Then update local.properties and WorkTickConfig.swift on each device
```

#### `GOOGLE_CLIENT_SECRET`
1. https://console.cloud.google.com/apis/credentials
2. Click your OAuth client name
3. Click **+ ADD SECRET** under "Client secrets"
4. Copy the new secret immediately
5. `fly secrets set GOOGLE_CLIENT_SECRET="GOCSPX-..."`
6. Click the trash icon next to the OLD secret to revoke it (after you've confirmed the new one works)

#### `GOOGLE_CLIENT_ID`
The Client ID isn't really a secret on its own (it's sent to browsers during OAuth), but if you want to rotate it: delete the OAuth client in Google Cloud Console and create a new one. You'll have to update the redirect URI authorization too.

### 2. Scrub git history (optional but recommended for public repos)

```bash
# Install BFG Repo-Cleaner: https://rtyley.github.io/bfg-repo-cleaner/
bfg --replace-text passwords.txt   # passwords.txt contains the leaked strings
git reflog expire --expire=now --all && git gc --prune=now --aggressive
git push --force
```

For a private repo with only you as a contributor, force-pushing a clean history is fine. For collaborative repos, coordinate the force-push with everyone else first.

### 3. Audit access logs

- **Fly.io**: `fly logs` — look for unauthorized API calls in the last hour
- **Google Cloud**: Cloud Console → IAM & Admin → Audit logs — filter for OAuth events

## Defense in depth

The above protects against accidental commits. For deeper protection:

- **Never paste secrets into chat tools** (Slack, Discord, Claude, etc.). Once posted, treat as compromised.
- **Use a password manager** (1Password, Bitwarden) to store the one canonical copy of each secret. Don't rely on `Notes.app`.
- **Enable 2FA** on Google Cloud and Fly.io accounts.
- **Limit OAuth scopes**: this app only requests `calendar.readonly`, the minimum needed.
- **Review `local.properties` before sharing your machine** — it contains the `API_SHARED_SECRET` in plaintext.
